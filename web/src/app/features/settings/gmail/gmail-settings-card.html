1. Google OAuth client

How to create your Google OAuth client (one-time, ~10 minutes)
  1. Open Google Cloud Console and create a project (e.g. “SwiftJob”).
  2. Enable the Gmail API for the project.
  3. Configure the OAuth consent screen (Google Auth Platform → Branding / Audience): user type External, add your Gmail address as a test user, and add the scope .../auth/gmail.readonly under Data Access.
  4. Create an OAuth client ID (Clients → Create client) of type Web application and add this Authorised redirect URI:
    {{ s.redirectUri }}
  5. Copy the Client ID and Client secret into the form below.

Tip: while the app is in Google's “Testing” status, Google expires the connection after 7 days. To avoid reconnecting weekly, set the app to “In production” (Audience → Publish app). For your own account the “unverified app” warning is expected — choose Advanced → Continue. Full guide: docs/GMAIL_SETUP.md.
