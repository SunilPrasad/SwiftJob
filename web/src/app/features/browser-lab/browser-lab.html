1. Try the browser yourself

lightbulb The browser opens on the right half of your screen. Snap SwiftJob to the left half (Windows + ←) to see both side by side. If the browser was already open, click Place beside SwiftJob.

The first start can take up to a minute (Playwright is downloaded once). Type in the window like any browser. Logins you make there are remembered in SwiftJob's own browser profile.

2. Let the AI fill the form

  • Demo applicant: Alex Demo · alex.demo@example.com · +44 7700 900123 · Demo_CV.pdf
  • The AI can only read the page and fill fields. It can't open other sites or run scripts.
  • It can never submit. Clicks on Submit/Apply/Send are blocked; submitting is always yours.
  • Take control stops the AI instantly; type in the window, then Resume and the AI continues from there.
  • Uses the AI model from Settings → AI model.
